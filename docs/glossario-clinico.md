# Glossário Clínico

Significado dos termos da optometria que aparecem nos campos do sistema. Escrito para que qualquer pessoa consiga entender o que cada dado representa, mesmo sem formação na área.

## Refratometria

É o exame que mede o grau do olho. No sistema, cada atendimento registra as medições separadamente para o **olho direito (OD)** e o **olho esquerdo (OE)**. Os campos de cada olho são:

- **Esférico** — O grau principal da lente. Valores positivos indicam hipermetropia (dificuldade para enxergar de perto) e negativos indicam miopia (dificuldade para enxergar de longe).
- **Cilíndrico** — O grau do astigmatismo, que é quando a córnea tem um formato irregular e causa visão distorcida. Quando não há astigmatismo, esse campo fica vazio.
- **Eixo** — A direção do astigmatismo, medida em graus de 0 a 180. Só faz sentido quando há valor cilíndrico.
- **Adição** — Grau extra que se soma ao esférico para leitura de perto. Usado em lentes multifocais ou bifocais, normalmente para pacientes com presbiopia (vista cansada).

## Acuidade Visual (AV)

É o quanto a pessoa consegue enxergar. No sistema aparece como dois campos:

- **AV Longe** — Capacidade de enxergar objetos distantes.
- **AV Perto** — Capacidade de enxergar objetos próximos, como texto de leitura.

Os valores são registrados como texto (ex: "20/20", "20/40") porque seguem notações clínicas padronizadas.

## Medições Pupilares

- **DNP (Distância Naso-Pupilar)** — Distância entre o centro do nariz e a pupila de cada olho, medida em milímetros. Cada olho tem sua própria DNP. É usada para centralizar a lente no eixo de visão do paciente.
- **Distância Pupilar (DP)** — Distância total entre as duas pupilas. No sistema, esse campo fica no atendimento (não dentro de cada olho) porque é uma medida única do par de olhos.

## Outros campos do atendimento

- **Queixa Principal** — O motivo que levou o paciente à consulta, descrito nas palavras dele (ex: "dor de cabeça ao ler", "visão embaçada de longe").
- **Sem Necessidade de Nova Correção** — Quando marcado, indica que o exame concluiu que o paciente não precisa trocar ou iniciar o uso de óculos/lentes.
- **Data Sugerida de Retorno** — Data recomendada para a próxima consulta de acompanhamento.
- **Lentes** — Tipos de lente recomendados para o paciente (ex: "monofocal", "multifocal", "bifocal").
- **Tratamentos** — Tratamentos aplicados à lente (ex: "antirreflexo", "fotocromático", "filtro de luz azul").

## Ótica de Origem

Indica a ótica parceira que encaminhou o paciente para a consulta. Quando o atendimento não tem ótica vinculada, o sistema considera como atendimento particular.
